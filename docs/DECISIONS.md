# Fruits ANA Manager 决策记录

## ADR-001 — 进行中任务必须有明确未完成标记

- Date: 2026-09-24
- Status: Accepted

### Context

源项目的 `docs/HANDOFF.md` 的 `In Progress` 章节同时包含实现说明、历史验证记录和提交信息。把章节中的所有普通列表项当成任务，会把已完成内容和说明性文字误报为“正在进行”。

### Decision

管理台只把 `In Progress` 章节中明确写成 `- [ ] 任务标题` 的条目计入“正在进行”。`[x]` 已完成项、普通 bullet、Git 未跟踪文件和最近提交都不构成进行中任务。

Git 工作区改动仍然读取并展示，但统一标记为“Git 观察项”；缺少 `HANDOFF.md` 时显示“来源缺失，无法判断”，不推断为零项或已完成。

### Consequences

- “正在进行”数字只反映源项目明确声明的未完成任务。
- TODO 待办、Git 改动、提交记录和来源缺口分别展示，避免混用。
- 源项目需要在 `HANDOFF.md` 中使用未完成复选框维护当前进行中的任务。
